# Аналитика обращений жилой недвижимости

Интерактивный дашборд для анализа обращений в жилищном девелопменте.

## О проекте

Проект разработан для демонстрации навыков:

- первичной обработки и контроля данных;
- расчёта KPI;
- построения интерактивной аналитики;
- фильтрации по нескольким параметрам;
- редактирования и экспорта записей;
- представления данных в понятном визуальном формате.

Использованы синтетические данные. Дашборд можно открыть локально без серверной базы данных.

## Данные

Набор содержит 600 записей за 2025 год.

Каждая запись включает:

- идентификатор обращения;
- дату обращения;
- жилой комплекс;
- источник обращения;
- менеджера;
- статус обращения;
- бюджет клиента;
- сумму сделки;
- дату последнего обновления.

## Возможности

- множественная фильтрация по проектам;
- множественная фильтрация по источникам;
- множественная фильтрация по менеджерам;
- фильтрация по статусам и периодам;
- выбор показателей динамики;
- расчёт количества обращений, сделок и конверсии;
- расчёт выручки и среднего бюджета;
- контроль просроченных обновлений;
- редактирование записей прямо в таблице;
- добавление новых записей;
- экспорт актуальных данных в CSV.

## Визуализация

Дашборд содержит:

- карточки ключевых показателей;
- динамику обращений и сделок;
- распределение обращений по источникам;
- распределение обращений по статусам;
- конверсию менеджеров;
- распределение обращений по жилым комплексам.

## Инструменты

- Python;
- Pandas;
- NumPy;
- HTML;
- CSS;
- JavaScript;
- Plotly;
- CSV.

## Ограничение данных

Данные полностью синтетические и не содержат реальных клиентов, объектов или коммерческой информации.

Показатели конверсии и выручки демонстрируют работу расчётов и аналитических компонентов, но не являются реальной статистикой бизнеса.

## Запуск

1. Откройте файл `real_estate_analytics_dashboard.html`.
2. Используйте стандартный браузер: Chrome, Edge или Firefox.
3. Выберите фильтры и временной период.
4. Измените значения в таблице.
5. Нажмите «Скачать CSV» для экспорта данных.
